📘 12 Frames – Scrolling Story

Welcome to IMEI Training

IMEI is the unique identification of each product. Managing IMEI correctly = managing stock and transactions correctly. Today, we will learn the full IMEI process in SAP & PDW.

Nam: “Linh, are you ready? Today we’ll learn IMEI from A–Z.”
Linh: “Yes, I want to understand everything clearly to avoid mistakes.”

Important Step: Select the Serial Number Tab

When receiving or issuing IMEI stock, always go to the “Serial Number” tab and enter IMEIs line by line.

Nam: “This is where you enter all IMEIs. Never forget this tab.”
Linh: “Got it. If I miss this tab, everything goes wrong.”

Scan IMEI Line by Line

SAP does not auto-jump between lines. Each IMEI must be scanned into the correct line manually.

Nam: “Scan one IMEI per line. Don’t scan continuously.”
Linh: “Yes, I’m scanning carefully line by line.”

Error: IMEI Quantity Less Than Required

If the number of IMEIs is less than the GR quantity, SAP blocks the process immediately.

IMEI Bot: “⚠️ Error: IMEI quantity < GR quantity.”
Nam: “Check if you missed any IMEI.”
Linh: “I’ll add the missing ones now.”

Check IMEI Before Transferring Warehouse

Always use ZMB52 to confirm where an IMEI currently belongs before doing any transfer.

Nam: “Check the warehouse of each IMEI first.”
Linh: “I’m checking the IMEI list now.”

Error: IMEI Not in Source Warehouse

If an IMEI does not exist in the selected warehouse, SAP will block the transfer.

IMEI Bot: “❌ Error 03 – IMEI not in selected warehouse.”
Linh: “Why is this IMEI in a different warehouse?”
Nam: “It belongs somewhere else. Check ZMB52 again.”

Understanding IMEI Errors

This error occurs when an IMEI is in another warehouse, already issued, or locked in a different status.

IMEI Bot: “IMEI does not exist in this warehouse. Please check the original warehouse.”
Linh: “Got it. I must check IMEI before doing anything.”

Issue Stock With Correct IMEI

IMEIs must match the Order Delivery (OD) exactly. Any mismatch causes stock errors immediately.

Nam: “Enter IMEI exactly as in the OD.”
Linh: “I’m matching IMEIs with the OD now.”

IMEI Accepted – System Confirmation

When IMEIs are correct, SAP displays a green confirmation message: IMEI accepted.

Linh: “I see the green message. That means it's OK, right?”
Nam: “Correct. That means the IMEI is valid.”

Warning: IMEI Already Used

If an IMEI has been used in any previous transaction, SAP will not allow it again.

IMEI Bot: “❌ Error 02 – IMEI already used.”
Linh: “Oh, this was returned by a customer before?”
Nam: “Yes. You must choose the IMEI that's still available.”

Check IMEI Stock Using ZMB52

Use ZMB52 to check where an IMEI is located, its status, and whether it is still available.

Linh: “I checked ZMB52. This IMEI is still in warehouse 001.”
Nam: “Good. This report must be checked daily.”

Training Completed

Mastering IMEI helps reduce store errors, speed up reconciliation, and improve accuracy in customer service.

Nam: “Congratulations Linh! You’ve completed the IMEI process.”
Linh: “Thank you. I feel much more confident now.”
IMEI Bot: “Status: Training Completed. Expected error rate: -90%.”
